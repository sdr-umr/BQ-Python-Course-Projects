Python Course Projects – BanoQabil

These projects were assigned as part of the Python course from BanoQabil.The projects are designed to practice Python programming concepts step by step, starting from basic functions and moving toward Object-Oriented Programming and file handling.

Projects Included

Week 1 – Simple Calculator
A basic calculator that performs addition, subtraction, multiplication, and division.

Week 2 – Temperature Converter
A program that converts Celsius to Fahrenheit and Fahrenheit to Celsius.

Week 3 – Menu-Driven Calculator
A menu-based calculator using conditions, loops, break, and continue.

Week 4 – Utility Module
A Python module for factorial, prime number checking, and square root calculations.

Week 5 – Contact Book
A simple contact book for adding and searching contacts using a dictionary.

Week 6 – Student Gradebook
A gradebook that calculates student grades and stores records in a CSV file.

Week 7 – Student Management System
A student management system using Object-Oriented Programming (OOP) to add, update, and view student records.
